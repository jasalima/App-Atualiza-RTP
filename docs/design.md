# Direção visual e referências

A revisão considera o uso diário de uma aplicação institucional de projetos de agricultura irrigada. Mantém a tipografia já instalada: família de interface para leitura e formulários, família de títulos para navegação e a fonte documental nos formulários oficiais.

Paleta principal: fundo sálvia claro `#f2f6f4`, branco `#ffffff`, petróleo `#173b43`, verde institucional `#216444`, azul água `#126b82` e âmbar `#8a600d`. Verde identifica conclusão; azul identifica ações; âmbar indica atenção; vermelho `#aa3027` indica erro. Os estados também têm texto, não dependem apenas de cor.

As telas operacionais conservam sua organização para não mudar o caminho aprendido pela equipe. O guia usa uma sequência de trabalho e tópicos com descrição curta; as páginas de assinatura priorizam o documento e a confirmação de identidade. Campos privados não entram nas ilustrações com dados reais.

Referência pesquisada via `npx skills find frontend-design`: [anthropics/skills@frontend-design](https://skills.sh/anthropics/skills/frontend-design). Instruções consultadas no [SKILL.md oficial](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md). Aplicadas: identidade ligada ao assunto, tokens de cor consistentes, hierarquia funcional, foco visível, contraste e contenção visual. A paleta foi revisada antes da implementação para preservar a marca existente, em vez de substituir a estrutura de navegação.
